# إدارة الحصص — تطبيق Expo

تطبيق محلي (بدون سيرفر) لإدارة مجموعات التدريس، الجدول التلقائي، الحضور، والاشتراكات الشهرية.

## التشغيل

```bash
npm install
npx expo start
```

افتح عبر Expo Go على أندرويد.

## البداية السريعة داخل التطبيق

1. المزيد → السنوات الدراسية → إضافة سنة وتحديد **بداية/نهاية كل فصل** من التقويم (الأشهر تُنشأ تلقائياً).
2. المجموعات → إضافة مجموعة + أيام الأسبوع + السعر (الوقت من منتقي الساعة).
3. الطلاب → إضافة طالب وربطه بمجموعة.
4. سجّل دفعة من المدفوعات (تاريخ الدفع من التقويم).
5. الرئيسية تعرض **إجمالي المدفوع** و**مين مدفعش**.

Build APK أصغر للاختبار: المشروع مضبوط على **arm64-v8a فقط**.

## البنية

- `app/` — شاشات Expo Router
- `src/db` — SQLite schema
- `src/repositories` — CRUD
- `src/services` — توليد الجدول، المديونية، النسخ الاحتياطي
- `src/i18n` — نصوص عربية

## ملاحظات تقنية

- Expo SDK 57 — راجع وثائق v57.
- RTL عربي مفعّل من الإقلاع.
- `babel.config.js` يضع Reanimated plugin آخراً.
- `metro.config.js` يمنع مراقبة `android/.gradle` على Windows.
